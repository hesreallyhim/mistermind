# Contributing

Thank you for visiting the repo. It's a little different because it doesn't contain source code for an application - the repo _is_ the "application". Gameplay relies on issues so I prefer that if you have a feature request, or you find a bug, or you want to contribute, use the relevant part of the Discussions tab instead. At the moment, if the application is stable, I don't have any immediate plans to accommodate external PRs unless already discussed. Plans for expanding the game already exist.

If you want to contribute to the longevity of this game, and other games to come, the best thing you can do is to support the maintainer via GitHub sponsorshipt - you are invited to become a sponsor for only $1 per month.
